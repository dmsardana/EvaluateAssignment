# Scoring Rubric - Quick Reference (Print This)

## Per-question score formula

```
Q = 0.40*CU + 0.20*AM + 0.20*SS + 0.10*NA + 0.10*PR
```

Each dimension scored 0, 0.5, or 1. Max per question: 1.00.

## The 5 dimensions and how to grade them

### CU - Conceptual Understanding (40%)

| Score | Indicator |
|---|---|
| 1.0 | Student demonstrates clear grasp of WHY the method works. Can identify the underlying principle. Correct setup that flows from understanding. |
| 0.5 | Method applied but understanding shaky. Right answer but no setup explanation. Or wrong answer but the right concept partially identified. |
| 0.0 | Conceptually confused. Wrong type of approach entirely (e.g. used algebraic method when graphical was clearly needed). |

### AM - Approach and Method (20%)

| Score | Indicator |
|---|---|
| 1.0 | Picked the right method efficiently. No detour through unnecessary algebra. Method appropriate for the JEE level. |
| 0.5 | Eventually got there but via a longer path. Or chose a valid but suboptimal method. |
| 0.0 | Picked wrong method, abandoned it midway, or applied a method without recognising why it fits. |

### SS - Step-by-Step Execution (20%)

| Score | Indicator |
|---|---|
| 1.0 | Every step shown, every step logically follows from the previous. No gaps. |
| 0.5 | Most steps shown but one or two key intermediate steps are skipped or unclear. |
| 0.0 | Big logical leaps. Steps don't connect. Hard to follow how they got from line 2 to line 3. |

### NA - Numerical Accuracy (10%)

| Score | Indicator |
|---|---|
| 1.0 | All arithmetic and algebra correct. Final answer matches the working. |
| 0.5 | One small calculation error (sign flip, transcription) but core working sound. Final answer slightly off. |
| 0.0 | Multiple errors. Or one error so significant that the conclusion is invalidated. |

### PR - Presentation and Clarity (10%)

| Score | Indicator |
|---|---|
| 1.0 | Final answer clearly boxed/highlighted. Working organised top-to-bottom. Readable handwriting. |
| 0.5 | Final answer present but not clearly marked. Or working ran into margins. Or numbering inconsistent. |
| 0.0 | No clear final answer. Working scrambled. Reader has to hunt for the conclusion. |

## Scoring shortcuts for common cases

| Situation | Recommended sub-scores |
|---|---|
| Fully correct, well-presented | 1, 1, 1, 1, 1 -> 1.00 |
| Right answer, weak working | 1, 1, 0.5, 1, 0.5 -> 0.85 |
| Right answer, no working shown | 0.5, 0.5, 0, 1, 0.5 -> 0.45 |
| Right method, arithmetic slip | 1, 1, 1, 0.5, 1 -> 0.95 |
| Right method, wrong final answer | 1, 1, 0.5, 0, 0.5 -> 0.75 |
| Wrong method but consistent execution | 0.5, 0, 1, 0.5, 1 -> 0.55 |
| Conceptually correct, sloppy | 1, 0.5, 0.5, 0.5, 0 -> 0.65 |
| Mostly right, one major slip | 1, 1, 0.5, 0.5, 1 -> 0.85 |
| Started right, abandoned | 0.5, 0.5, 0, 0, 0.5 -> 0.35 |
| Blank or unrelated work | 0, 0, 0, 0, 0 -> 0.00 |
| Working illegible | mark "cannot evaluate", treat as 0 with scan note |

## Bands

| Band | Range | Color | Action |
|---|---|---|---|
| Trailblazer | >= 75% | Green | Promote |
| Qualifier | 60-74% | Blue | (WA) Promote / (QA, AA) revise |
| Developing | 45-59% | Amber | Repeat current tier |
| Foundational Gaps | < 45% | Red | Concept refresh first |

---

## Tier promotion ladder

```
WA --(>=60%)-->  QA --(>=75%)-->  AA --(>=75%)-->  mastery
                                                       v
                                                  next topic
```

ZA (Quiz) sits parallel to WA, auto-graded by Google Forms, NOT in this evaluation flow.

---

## Scan quality grades

| Grade | Color | Use for |
|---|---|---|
| Excellent | Green | Perfect scan, no issues |
| Good | Blue | Readable, minor imperfection |
| Acceptable | Amber | Visible issue but readable |
| Poor | Red | Parts illegible/missing |

3+ Poor questions = return submission for re-scan, do not evaluate.
